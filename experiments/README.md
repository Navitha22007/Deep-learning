# Deep Learning Laboratory

## Experiment
Activation Functions and Optimization Algorithms in Artificial Neural Networks (ANN)

## Aim
To analyze the impact of different activation functions and optimization algorithms on ANN performance.

## Software Used
- Python
- TensorFlow
- Google Colab
- GitHub
- Matplotlib

## Dataset
Fashion MNIST

## Activation Functions
- Sigmoid
- Tanh
- ReLU

## Optimizers
- SGD
- Momentum
- RMSProp
- Adam

## Results
- ReLU achieved the highest validation accuracy among the activation functions.
- Adam optimizer converged the fastest and produced the best validation accuracy.
